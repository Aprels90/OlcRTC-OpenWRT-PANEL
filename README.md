# OlcRTC-OpenWRT

Панель содержит актуальную сборку клиента OlcRTC для ARM64 и AMD64.

> [!IMPORTANT]
> Актуальный OlcRTC использует YAML-конфиг и протокол OLC2. Сервер и клиент должны использовать совместимые сборки и одинаковые `transport`, `room.id` и `crypto.key`. Ошибка `frame token mismatch` обычно означает несовместимые версии или неверные параметры подключения.

Панель управления LuCI для запуска [OlcRTC](https://github.com/openlibrecommunity/olcrtc) в режиме клиента на роутере с OpenWRT.

## Что это такое

OlcRTC запускается на роутере как SOCKS5-прокси.
Весь трафик браузера или устройства, направленный через этот прокси, проходит по зашифрованному WebRTC-туннелю через разрешённый в России сервис, что позволяет обходить блокировки.

Данный проект добавляет удобный веб-интерфейс в стандартное меню LuCI (**Службы → OlcRTC**).

## Возможности

- **URI-импорт** — вставьте строку `olcrtc://…` от сервера, все параметры заполнятся автоматически
- **Подписки** — добавьте `https://…` ссылку на sub.md файл: карточки серверов обновляются автоматически, клик по карточке применяет настройки одним нажатием; поддерживается несколько подписок одновременно
- Выбор сервиса: **Jitsi**, **Telemost**, **Wildberries Stream**
- Выбор транспорта: **datachannel**, **vp8channel**, **seichannel**, **videochannel**
- Встроенная матрица совместимости "Сервис × Транспорт"
- Полная настройка параметров каждого транспорта (vp8-fps/batch, sei-fps/batch/frag/ack-ms, video-codec/размер/fps/битрейт/hw и др.) — секции показываются только для выбранного транспорта
- Ввод Room ID, ключа шифрования, SOCKS5 хоста/порта/логина/пароля и DNS-сервера
- Автосохранение при изменении любого поля — кнопка «Сохранить» не нужна
- Кнопки **Старт** и **Стоп**
- Индикатор статуса с PID
- Отображение логов в реальном времени

## Требования

- OpenWRT с LuCI (проверено на OpenWrt 24.10 и OpenWrt 25.12.1 & LuCI 0.7.14)
- Архитектура: **ARM64** (aarch64) или **AMD64** (x86-64) — выбирается при установке
- Свободное место: ~21 МБ
- Удалённый сервер (VPS) с запущенной серверной частью OlcRTC.

## Установка на роутер

Подключитесь к роутеру по SSH и выполните:

```sh
sh -c "$(wget -qO- https://raw.githubusercontent.com/Aprels90/OlcRTC-OpenWRT-PANEL/main/install.sh)"
```

Скрипт устанавливает LuCI-панель и скачивает подходящий актуальный бинарник OlcRTC из этого репозитория. Сборки уже подготовлены для ARM64 и AMD64.

На сервере и роутере должны быть совместимые версии OlcRTC. Старые бинарники могут вызывать `frame token mismatch` при использовании `vp8channel`, `videochannel` или `seichannel`.

После установки откройте LuCI → **Службы → OlcRTC**.

### Быстрый старт через URI

Если сервер выдал строку подключения вида `olcrtc://…` — вставьте её в поле **«Подключение по URI / Подписка»**, параметры заполнятся автоматически. Нажмите **Старт**.

### Подписки

Если у вас есть ссылка на sub.md-файл с несколькими серверами:

1. Вставьте `https://…` ссылку в то же поле
2. Появится блок с карточками серверов
3. Нажмите на карточку — параметры применятся автоматически
4. Подписка обновляется в фоне с интервалом, заданным в файле

Можно добавить несколько подписок одновременно; каждая хранится в UCI и переживает перезагрузку.

### Ручная настройка

| Параметр | Описание |
|---|---|
| **Сервис** | Provider: Jitsi, Telemost или Wildberries Stream — должен совпадать с сервером |
| **Транспорт** | Протокол передачи: datachannel, vp8channel, seichannel, videochannel — должен совпадать с сервером |
| **Room ID** | ID комнаты — скопируйте из логов сервера при первом запуске |
| **Ключ шифрования** | 64-символьная HEX-строка — скопируйте с сервера |
| **SOCKS5 адрес/порт** | Хост и порт локального прокси (по умолчанию 127.0.0.1:1080) |
| **Логин/пароль SOCKS5** | Опционально; если заданы — включается RFC 1929 аутентификация |
| **DNS-сервер** | DNS внутри туннеля (по умолчанию 1.1.1.1:53) |

## Использование прокси

После запуска на роутере доступен SOCKS5-прокси:

```
Хост:  <IP роутера>
Порт:  1080  (или тот, что вы указали)
Тип:   SOCKS5
```

Укажите эти настройки в браузере, приложении или в установленном сервисе (например, podkop).

## Удаление

### Удаление Podkop

Если Podkop больше не нужен, удалите его командой:

```sh
opkg remove luci-i18n-podkop-ru luci-app-podkop podkop
```

### Удаление панели OlcRTC

```sh
sh -c "$(wget -qO- https://raw.githubusercontent.com/Aprels90/OlcRTC-OpenWRT-PANEL/main/uninstall.sh)"
```

Или вручную:

```sh
/etc/init.d/olcrtc stop
/etc/init.d/olcrtc disable
rm -f /usr/bin/olcrtc
rm -f /etc/init.d/olcrtc
rm -f /etc/config/olcrtc
rm -f /usr/share/luci/menu.d/luci-app-olcrtc.json
rm -f /usr/share/rpcd/acl.d/luci-app-olcrtc.json
rm -rf /www/luci-static/resources/view/olcrtc
/etc/init.d/rpcd restart
/etc/init.d/uhttpd restart
```
